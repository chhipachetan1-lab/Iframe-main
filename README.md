# 🖼️ HTML Iframe & Multi-Page Layout Project

A comprehensive web development project showcasing HTML `<iframe>` integration, multi-page routing, custom CSS positioning, and responsive layouts. This repository serves as a structured collection of practical web design modules and lab assignments.

---

## 🚀 Key Features

* **HTML Iframe Implementation:** Demonstrates embedding external or internal sub-pages cleanly within a parent window.
* **Modular Page Structure:** Includes dedicated pages for authentication (`Login_Signup-main`), contact forms, about sections, and galleries.
* **CSS Layout & Positioning:** Built-in test pages to experiment with element positioning, styling, and asset integration (`position.html`).
* **Lab Assignments:** Houses organized HTML files ranging from `Assignment1.html` to `Assignment10.html`.
